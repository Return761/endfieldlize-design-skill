# Graphic composition

Start with the task and selected interaction model. From reference images extract compositional relationships such as the dominant mass, negative space, information density, angular rhythm, typographic scale and how layers enter or recede. Only use imagery or other assets with appropriate provenance.

Define a visual grammar before polishing components. Choose where to anchor the layout and how marks express selection, scope, measurement or progression. Use changes in scale, topology, overlap, alignment and repetition to form the composition. Let utility text and focus indicators stay readable in every mode. For experimental directions, investigate materially different arrangements with awkward real content before settling on one.

Use deterministic SVG primitives where they fit. Write a new generator when the design calls for a new algorithm. Bind live data to marks with a documented mapping. Provide a static readout and reduced-motion behavior where motion carries information.

Read [composition techniques](references/grammar.md) for the available visual approaches and [graphics CLI](references/graphics.md) when generating assets. Record choices and tradeoffs in `CompositionSpec` and link the actual rendered prototype for design-evaluation.
