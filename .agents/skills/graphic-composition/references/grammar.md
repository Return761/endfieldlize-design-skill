# Building a visual grammar

| Approach | Compositional move to try |
| --- | --- |
| Experimental Graphic Design | Change the dominant reading axis or let two sections share a contour. Test whether the primary action survives the disruption. |
| Neo-Constructivism | Use diagonal forces, cropped masses and deliberate repetition to direct attention to the current object. |
| Editorial Layout | Let title, image and annotations use different column spans. Establish hierarchy through scale and spacing. |
| Industrial Information Graphics | Use rulers, callouts and alignment marks for actual units, offsets and relationships. |
| Graphic Maximalism | Concentrate detail in one field and reserve quiet space for controls. Distinguish primary information from texture. |
| FUI / HUD | Anchor a reticle or gauge to a live object and explain its units or state. Reserve chrome for changes the user can act on. |
| Asymmetrical Composition | Balance heavy and light regions with unequal spans and one shared axis. Preserve reading order at narrow widths. |
| Typography as Geometry | Use cropped or outlined display type as shape, while semantic headings carry the readable label. |
| Procedural Motion Graphics | Map the changing data to position, amplitude or repetition. Cap update cost and provide a stable reduced-motion state. |

When using the supplied direction, test hard-edged black/white contrasts, localized safety color, clipped fields, and registered layers. Derive original marks and surfaces from the prototype data and intent.

For this toolkit's default direction use Montserrat first and HarmonyOS Sans second for titles, labels, navigation and body text. Use JetBrains Mono selectively where aligned figures aid scanning, such as timecodes, measurements and compact IDs. Use geometry, hierarchy, data binding and purposeful motion to establish the technical character. Build surfaces from neutral white, gray and black. Choose a high-contrast accent suited to the work and reserve it for meaningful emphasis and state. Follow a project's established typography and palette when the task calls for them.

Consider Amarillo USAF for a few oversized map region names, short graphic titles or large zone codes such as `SECTOR 04`. Use it when its angular lettering reinforces the graphic's geometry. Keep the rest of the visual hierarchy in the default typefaces and preview the display text at each intended size. Use a locally available font where licensed.
