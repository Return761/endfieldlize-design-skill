# AI 对话管理工作空间

## 任务样本

空间层级为组织 → Research → Q4 → Evaluation。Eval B 从会话 revision 17 分出，在 14:02 失败。它读取 Ops / Baselines 的 Baseline C 所产出的 report v3。另有 report v4，属于同一个文档但无法解释此次失败。决策记录位于父会话。用户要恢复失败分支、核对两个结果并打开共享证据。

## 三个独立方向

| 方向 | 基础单元和操作 | 复杂任务路径 | 主要代价 |
| --- | --- | --- | --- |
| 空间关系图 | 空间聚合为簇。聚焦分支后显示父级、关联对象和有类型的跨空间边。固定两个对象进入比较。 | 展开 Q4 → 聚焦 Eval B → 固定 → 沿 report v3 依赖 → 固定 Baseline C → 在比较内打开 report v3。 | 高扇出会淹没边。收起未聚焦的簇，边按类型计数，明细按需展开。 |
| 执行车道 | 时间轴上的分支运行。设定窗口或固定 checkpoint，按共同 base revision 对齐。 | 筛选失败 → 锚定 14:02 → 打开关联车道 → 按 report v3 对齐 → 展开证据。 | 跨长时间范围的材料会离开视野。固定 checkpoint 并给出返回当前时间的操作。 |
| 证据索引 | 每个素材版本拥有生产者、消费者和引用的决策。可围绕证据反查对话。 | 按事件标签找到 report v3 → 并列对照 producer 与 consumer → 回到 Eval B 的决策记录。 | 用户只知道失败分支时，文本或状态搜索需要先找到一个入口。 |

## 选择

以空间关系图作为主界面。主画面由空间层级和关系边组成，焦点状态提供按关系类型分组的表格。时间仅用于单分支尝试历史，证据索引用于比较板中的版本跳转。三个路径共享对象 ID。比较板关闭后恢复原焦点，跨空间权限不足时保留引用和返回位置。

- 空间缩小时聚焦节点与面包屑沿一条阅读轴排列。键盘可通过标准按钮进入关系表、固定分支、选择版本和回到上一个焦点。
- 重试生成新的 run attempt。旧失败、原始日志和报告版本保留。无权限、报告删除和没有依赖都使用可读的独立反馈。
- 高密度验收样本可包含 200 个对话、40 条跨空间引用、80 字标题与多个共享产物。当前为方案与结构化交互样例，操作数和空间模型表现待实测。
